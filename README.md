# Quiz App

A responsive React quiz application built with Vite. It includes a timed multiple-choice quiz, answer tracking, score calculation, and a final result screen.

## Features

- 10-question general knowledge quiz
- Countdown timer for each session
- Multiple-choice answers with selection state
- Score and percentage result summary
- Clean, mobile-friendly UI

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
